# Kitaphana — демонстрационная библиотека

Откройте `dist/index.html` в современном браузере. Установка зависимостей не нужна. Для HTTP-предпросмотра: `node server.cjs`, затем http://127.0.0.1:4173.

Каталог содержит 32 записи из публичного каталога предоставленного сайта. Новый интерфейс на русском языке включает поиск, фильтры, избранное, бронирование, кабинет читателя, выдачу/возврат в демонстрационном режиме библиотекаря и тёмную тему. Все изменения сохраняются в localStorage этого браузера. При смене браузера данные не переносятся.

Сценарий демонстрации: каталог → доступная книга → бронирование → режим библиотекаря → выдача → кабинет → продление → библиотекарь → возврат → история.

Это локальная модель процессов, без настоящих аккаунтов, серверной авторизации и общей базы данных. Записи листа ожидания демонстрируют отсутствие экземпляров в исходном каталоге. Электронные материалы содержат короткие специально созданные памятки, а не полные тексты книг. Обложки созданы средствами CSS. Для шрифтов используется Google Fonts с системным запасным шрифтом; остальные ресурсы локальные.

Исходный сайт: https://kitaphana-library.kgijow.chatgpt.site. Системные настройки прокси не менялись.
